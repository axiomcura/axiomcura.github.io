# Documents Folder

This folder contains downloadable documents for the website.

## Adding Your CV

To add your CV:
1. Place your CV PDF file in this folder and name it `Erik-Serrano-CV-September-2025.pdf`
2. The "Download CV" button on the website will link to this file (as referenced in `index.html`)
3. When clicked, it will open your CV in a new browser tab

If you change the filename, make sure to also update the link in `index.html` to match the new filename.
