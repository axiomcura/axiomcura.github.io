# Documents Folder

This folder contains downloadable documents for the website.

## Adding Your CV

To add your CV:
1. Place your CV PDF file in this folder and name it `cv.pdf`
2. The "Download CV" button on the website will automatically link to it
3. When clicked, it will open your CV in a new browser tab

Make sure your CV file is named exactly `cv.pdf` for the link to work properly.
